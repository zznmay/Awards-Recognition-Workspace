# 评奖评优工作台

面向高校奖学金评定流程的单文件 Web 应用仓库。本仓库从原有存档目录整理而来，**仅纳入最新有效版本**，供后续使用 Git / GitHub 做版本管理。整理过程未改动任何原有文件内容与功能。

---

## 一、项目概述

| 项目 | 说明 |
|---|---|
| 应用形态 | 单个 `index.html`，纯前端、零依赖、零构建、无本地外部资源引用 |
| 运行方式 | 浏览器直接打开即可使用 |
| 业务范围 | 基础信息库 + 8 个评定工具（综测加分、模块加分、综测排名、符合等级、最终认定、三好学生、优秀学生干部、行知专业奖学金）+ 公示管理 |
| 数据存储 | 浏览器 `localStorage`，键名 `wb_pjpy_state_v1`；业务数据不随仓库分发 |
| 核心机制 | 逐层「确认门禁」（确认锁定后下一层才可用）与「版本留存」（`stage.lX.versions`），上游切换版本会通知下游 |

## 六、版本管理约定

1. **单一主文件**：只维护根目录 `index.html`，不再手工复制「XX版本.html」留档；历史版本由 Git 提交历史与标签追溯。
2. **提交粒度**：一次功能性改动对应一次提交，提交信息建议 `type: 简述`（如 `fix: 修正公示查询页缓存`、`feat: 等级调整面板增加搜索`）。
3. **版本标签**：可发布节点打 `vX.Y.Z` 标签；重大功能递增次版本号，缺陷修复递增修订号。当前基线标签为 `v3.4.0`。
4. **改动校验**：每次修改后用 `shasum -a 256 index.html` 核对，并在提交前确认工作区 diff 仅在预期范围。
5. **敏感数据**：学生名单、成绩、`localStorage` 导出文件、备份 JSON 一律不得提交，相关模式已由 `.gitignore` 拦截。
