批次概况

公示单

选定工具层与版本，生成学生查询公示页（单文件发学生群）；学生凭学号+姓名查询本人结果，异议经外部表单收集后在此登记回复。

异议登记与回复

学生在表单提交的异议导出 CSV 后在此批量导入，也可手工登记；采纳的异议将引导重算对应层（下游自动失效）。

数据备份（本地存储）

数据保存在本浏览器中，建议定期导出 JSON 快照；换设备或清缓存前务必先导出。

公示分享短链接口

已内置云端只读接口，开箱即用：公示分享链接是 https://…/?pub=s.xxxxxxxx 这样的 短链，数据存云端，学生打开时实时拉取；你在后台更新公示后，学生刷新即可看到最新结果，链接不变。若接口不可用会自动退回「数据内嵌链接」（较长但无需后端）。你也可以换成自建接口地址。
链接以 ?pub= 开头（用 query 参数而非 hash），可避开腾讯云测试域名的中间风险提醒页、保证点完跳转后不掉路径，直接进入公示查询页。

跨浏览器云同步（零后端）

基于 GitHub 私有 Gist 同步，多设备共用同一份数据。Token 仅存本机浏览器，不会上传到云端。
